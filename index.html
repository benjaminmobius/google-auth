01 / Overview

Personal Auth Portal

This portal is a private configuration utility designed exclusively for a single-user Tailscale network integration. It serves as the designated OAuth verification endpoint to facilitate localized credential handshakes across an authenticated private mesh.

Network Scope Private Tailnet Mesh
Access Model Single-User Administrative
Token Custody Strictly Local Environment
02 / Data Governance

Privacy Policy

Zero Data Collection: This application does not collect, track, store, log, or share any user data, personal information, telemetry, cookies, or analytics of any kind.

Localized Token Handling: All authentication tokens, OAuth authorization codes, and session credentials generated during the authorization flow remain strictly localized to the user's private environment and authenticated Tailscale network nodes. No credentials or identity payloads are transmitted to, retained by, or accessible from any external third-party server.

  • No Personal Data Storage
  • No Third-Party Analytics
  • No External Token Relay
  • Local Environment Custody Only
